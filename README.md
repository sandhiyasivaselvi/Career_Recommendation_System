# **Career Recommendation System**

## **Problem Statement**

Many students and job seekers face difficulties in choosing the right career path because they are unaware of their strengths, skills, interests, and suitable job opportunities. Traditional career guidance methods are often time-consuming and may not provide personalized recommendations. Therefore, there is a need for an intelligent Career Recommendation System that uses Machine Learning techniques to analyze user data and suggest suitable career options based on their skills, interests, academic performance, and preferences.

## **Objectives**

The main objective of this project is to develop a Machine Learning-based Career Recommendation System that helps users identify suitable career paths based on their skills, interests, academic performance, and personal preferences. The system aims to analyze user data, apply machine learning algorithms to find patterns and relationships, and provide personalized career recommendations. It also assists students and job seekers in making informed career decisions, reduces uncertainty in career selection, and improves the efficiency and accuracy of career guidance through data-driven recommendations.

### Dataset Information

The dataset used for the Career Recommendation System contains information about students, including their skills, interests, academic performance, and preferred career domains. The data is collected from online surveys, career guidance datasets, and publicly available educational sources.

**Dataset Attributes:**

* Student ID
* Gender
* Age
* Academic Percentage/CGPA
* Programming Skills
* Communication Skills
* Problem-Solving Ability
* Technical Skills
* Interests (AI, Data Science, Web Development, Cyber Security, etc.)
* Preferred Working Area
* Career Category (Target Output)

**Target Variable:**

* Recommended Career Path (e.g., Data Scientist, Software Developer, AI Engineer, Web Developer, Cyber Security Analyst, Business Analyst)


**Sample Career Recommendations:**

* Data Scientist
* Machine Learning Engineer
* Software Developer
* Web Developer
* Cyber Security Analyst
* Business Analyst
* Cloud Engineer
* Database Administrator

This dataset is preprocessed by handling missing values, encoding categorical data, and normalizing numerical features before training the machine learning model.
